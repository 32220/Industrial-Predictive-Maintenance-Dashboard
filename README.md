# Industrial-Predictive-Maintenance-Dashboard
End-to-end predictive maintenance analytics project using Python for data cleaning and feature engineering, and Power BI for interactive dashboard development. Includes machine health monitoring, maintenance risk assessment, failure analysis, and operational insights.
# Data source: [Industrial Machine Predictive Maintenance](https://www.kaggle.com/datasets/tatheerabbas/industrial-machine-predictive-maintenance)

## Project Overview
A Business Intelligence project that transforms industrial machine sensor data into actionable maintenance insights using Python and Power BI.

## Objectives
- Clean and preprocess machine sensor data
- Engineer predictive maintenance features
- Build an interactive dashboard
- Support proactive maintenance decisions

## Tools
- Python
- Pandas
- Scikit-learn
- Power BI
- DAX

## Engineered Features
- Machine Health Index
- Maintenance Risk
- Temperature Difference
- Health Status
- Maintenance Status

## Dashboard Features
- Fleet Health Monitoring
- Failure Analysis
- Repair Cost Analysis
- Machine Health Trends
- Maintenance Prioritization
