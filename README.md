# Industrial-Predictive-Maintenance-Dashboard
End-to-end predictive maintenance analytics project using Python for data cleaning and feature engineering, and Power BI for interactive dashboard development. Includes machine health monitoring, maintenance risk assessment, failure analysis, and operational insights.
Data source: Industrial Machine Predictive Maintenance
